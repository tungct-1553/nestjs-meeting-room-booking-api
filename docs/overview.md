# Khóa học NestJS - Xây dựng REST API

## 1. Kiến thức đạt được

Sau khi hoàn thành khóa học, học viên sẽ nắm vững:

- Khả năng tổ chức ứng dụng theo chuẩn kiến trúc của NestJS (Module – Controller – Provider), sử dụng dependency injection và hiểu rõ vòng đời của một request.
- Kỹ năng xây dựng REST API hoàn chỉnh bao gồm: cấu hình routing, xử lý param/query/body, sử dụng DTO và validation với class-validator, áp dụng Pipe, chuẩn hóa response, sinh tài liệu bằng Swagger và quản lý API versioning.
- Tích hợp tầng dữ liệu thông qua ORM, thao tác với entity, repository, thực hiện CRUD và migration cơ bản.
- Cấu hình tính năng xác thực, đăng ký/đăng nhập bằng JWT, sử dụng Guard và phân quyền theo vai trò (RBAC).
- Quản lý ngoại lệ bằng exception filter, HttpException, thiết lập ConfigModule và logging cơ bản.
- Viết unit test cho controller và service với Testing Module, đảm bảo coverage code đạt yêu cầu.
- Phần nội dung nâng cao: Làm chủ custom provider, dynamic module, lifecycle hook, sử dụng interceptor, custom decorator, serialization, quản lý transaction, xử lý tranh chấp ghi, tránh N+1, cấu hình refresh token, rate limiting, bảo mật CORS, health check, graceful shutdown và viết E2E test bằng supertest.

## 2. Thời lượng và nội dung

Khóa học có tổng thời lượng 70 giờ (10 ngày), bao gồm 63 giờ học lý thuyết/thực hành và 7 giờ dành cho quá trình review, xử lý comment của pull request.

Các nội dung cốt lõi:

- Phần 1 - Nhóm điều kiện HTTP & Web nền tảng: Mô hình client-server, REST, HTTP request/response và status code.
- Phần 2 - Kiến trúc & DI: Module, Controller, Provider và vòng đời request.
- Phần 3 - REST API: Validation, DTO, Pipe, chuẩn hóa response và Swagger API.
- Phần 4 - Tầng dữ liệu: ORM, entity, CRUD và migration.
- Phần 5 - Auth & Phân quyền: JWT, Guard và RBAC.
- Phần 6 - Xử lý lỗi & Vận hành: Exception filter, ConfigModule và logging.
- Phần 7 - Testing & Code Review: Unit test, xử lý comment và hợp nhất 9 pull request.
- Phần 8 - Nâng cao: Custom provider, interceptor, transaction nâng cao, policy-based authorization, graceful shutdown và E2E testing.
